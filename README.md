Проєкт для навчання нейромережі грати в шахи: власний шаховий движок,
конвертер партій Lichess у датасет, CNN-модель із двома головами (policy/value),
переднавчання на партіях людей та донавчання через self-play (RL).

Графіки статистики навчання знаходяться у папках pretrain_stats та train_stats.

## Структура проєкту

| Файл           | Призначення                                                                 |
|----------------|------------------------------------------------------------------------------|
| `engine.py`    | Самописний шаховий движок: правила гри, генерація легальних ходів, кодування/декодування ходів, детекція мату/пату/нічиєї. |
| `converter.py` | Читає архів партій Lichess (`.pgn.zst`), фільтрує їх за рейтингом/результатом і будує датасет (`dataset.csv`) для переднавчання. |
| `models.py`    | Архітектура `ChessModel` (ResNet-подібна CNN із policy- та value-головами) та обгортка `PlayerModel` для збереження/завантаження чекпоінтів. |
| `pretrain.py`  | Supervised-переднавчання моделі на датасеті реальних партій (`dataset.csv`). |
| `train.py`     | Self-play навчання з підкріпленням (REINFORCE + value baseline) поверх переднавченої моделі, з паралельними іграми через `multiprocessing.Pool`. |

## Встановлення

```bash
pip install -r requirements.txt
```

Потрібен Python 3.9+. Для навчання (`train.py`, `pretrain.py`) наполегливо рекомендується GPU з CUDA.

## Пайплайн навчання

### 1. Підготовка датасету

Завантажте архів партій із [Lichess Database](https://database.lichess.org/) (наприклад,
`lichess_db_standard_rated_2017-02.pgn.zst`) та покладіть його поруч зі скриптом
(або виправте шлях `file_path` у `converter.py`).

```bash
python converter.py
```

Скрипт відфільтрує партії за критеріями:
- завершення `Termination == "Normal"`;
- рейтинг обох гравців ≥ 1000;
- результат `1-0` або `0-1` (нічиї пропускаються).

Результат — `dataset.csv` із колонками `value_target`, `policy_target`, `board`, `turn`,
по `TOTAL_SAMPLES` позицій на кожен результат (налаштовується константою у файлі).

### 2. Переднавчання (supervised)

```bash
python pretrain.py
```

Навчає `ChessModel` на `dataset.csv` передбачувати хід експерта (policy) та результат
партії (value). Чекпоінти зберігаються в `pretrain_models/pretrain_model{epoch}`,
статистика — у `pretrain_stats/stats.csv`. Перед запуском створіть ці папки:

```bash
mkdir -p pretrain_models pretrain_stats
```

Прапорець `IS_REPEAT` у файлі вмикає донавчання з існуючого чекпоінта.

### 3. Self-play RL-донавчання

```bash
python train.py
```

Завантажує чекпоінт, зазначений у `CHECKPOINT_PATH` (за замовчуванням
`pretrain_models/pretrain_model10`), і донавчає модель через self-play:
декілька паралельних партій (`N_ENVS`) генеруються воркерами, потім рахуються
returns/advantage та градієнти за policy- та value-лоссами. Моделі зберігаються в
`train_models/`, статистика — у `train_stats/`:

```bash
mkdir -p train_models train_stats models stats
```

## Формат подання позиції

- Клітинки движка кодуються як `row*10 + col`, `row, col ∈ 1..8` (наприклад, `e2` → `25`).
- Для моделі дошка конвертується в тензор `[12, 8, 8]`: 6 площин для своїх фігур
  і 6 — для фігур супротивника (пішак/кінь/слон/тура/ферзь/король).
- Ходи кодуються в індекс `0..4671` (64 клітинки × 73 площини ходу, як у AlphaZero).
