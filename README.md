# Chess Pet Project

Проект для обучения нейросети играть в шахматы: собственный шахматный движок,
конвертер партий Lichess в датасет, CNN-модель с двумя головами (policy/value),
предобучение на партиях людей и дообучение через self-play (RL).

Графики статистики обучения находятся в папках pretrain_stats и train_stats.

## Структура проекта

| Файл           | Назначение                                                                 |
|----------------|------------------------------------------------------------------------------|
| `engine.py`    | Самописный шахматный движок: правила игры, генерация легальных ходов, кодирование/декодирование ходов, детекция мата/пата/ничьей. |
| `converter.py` | Читает архив партий Lichess (`.pgn.zst`), фильтрует их по рейтингу/результату и строит датасет (`dataset.csv`) для предобучения. |
| `models.py`    | Архитектура `ChessModel` (ResNet-подобная CNN с policy- и value-головами) и обёртка `PlayerModel` для сохранения/загрузки чекпоинтов. |
| `pretrain.py`  | Supervised-предобучение модели на датасете реальных партий (`dataset.csv`). |
| `train.py`     | Self-play обучение с подкреплением (REINFORCE + value baseline) поверх предобученной модели, с параллельными играми через `multiprocessing.Pool`. |

## Установка

```bash
pip install -r requirements.txt
```

Требуется Python 3.9+. Для обучения (`train.py`, `pretrain.py`) настоятельно рекомендуется GPU с CUDA.

## Пайплайн обучения

### 1. Подготовка датасета

Скачайте архив партий с [Lichess Database](https://database.lichess.org/) (например,
`lichess_db_standard_rated_2017-02.pgn.zst`) и положите его рядом со скриптом
(или поправьте путь `file_path` в `converter.py`).

```bash
python converter.py
```

Скрипт отфильтрует партии по критериям:
- завершение `Termination == "Normal"`;
- рейтинг обоих игроков ≥ 1000;
- результат `1-0` или `0-1` (ничьи пропускаются).

Результат — `dataset.csv` с колонками `value_target`, `policy_target`, `board`, `turn`,
по `TOTAL_SAMPLES` позиций на каждый исход (настраивается константой в файле).

### 2. Предобучение (supervised)

```bash
python pretrain.py
```

Обучает `ChessModel` на `dataset.csv` предсказывать ход эксперта (policy) и результат
партии (value). Чекпоинты сохраняются в `pretrain_models/pretrain_model{epoch}`,
статистика — в `pretrain_stats/stats.csv`. Перед запуском создайте эти папки:

```bash
mkdir -p pretrain_models pretrain_stats
```

Флаг `IS_REPEAT` в файле включает дообучение с существующего чекпоинта.

### 3. Self-play RL-дообучение

```bash
python train.py
```

Загружает чекпоинт, указанный в `CHECKPOINT_PATH` (по умолчанию
`pretrain_models/pretrain_model10`), и дообучает модель через self-play:
несколько параллельных партий (`N_ENVS`) генерируются воркерами, затем считаются
returns/advantage и градиенты по policy- и value-лоссам. Модели сохраняются в
`train_models/`, статистика — в `train_stats/`:

```bash
mkdir -p train_models train_stats models stats
```

## Формат представления позиции

- Клетки движка кодируются как `row*10 + col`, `row, col ∈ 1..8` (например, `e2` → `25`).
- Для модели доска конвертируется в тензор `[12, 8, 8]`: 6 плоскостей для своих фигур
  и 6 — для фигур противника (пешка/конь/слон/ладья/ферзь/король).
- Ходы кодируются в индекс `0..4671` (64 клетки × 73 плоскости хода, как в AlphaZero).
